# Original Skout logos

These original PNG files are included, copied unchanged from the local Skout Labs asset folders and matched to the brief:

- skout-labs.png
- budget-skout.png
- recipe-skout.png
- travel-skout.png
- expedition-skout.png

Retain these case-sensitive filenames when replacing images. Images render with Next.js Image using object-fit: contain. Restart development or rebuild production after replacement, then run npm run check:assets. The company logo also supplies the site icon and social card.
